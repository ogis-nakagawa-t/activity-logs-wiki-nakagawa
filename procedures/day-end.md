# 本日の業務を終了する

1. 業務開始時に作った `10_Daily/YYYY/MM/DD.md`（日付をまたいだ場合も、開始時のファイル）の「⏱ 工数」セクションを確認し、次の順に整える。
   1. 工数表のプロジェクトコードの空欄を `project-codes.md` で補う（日中に登録された分を反映する。照合は procedures/project-codes.md の「参照」に従う）。
   2. 工数表の「合計」行が各行の合計と一致しているか確認し、ずれていれば更新する。
   3. `project-codes.md` に未登録で、コードが空欄のままの行があれば、該当する `@[…]` を報告する。
2. `git add -A` を実行し、続けて `git commit -m "docs(daily): YYYY-MM-DD の作業ログを記録した"` を実行する（`&&` は使わない。メッセージは `git-conventions` スキルに従う）。pushはせず、「push は利用者が行ってください」と伝える。

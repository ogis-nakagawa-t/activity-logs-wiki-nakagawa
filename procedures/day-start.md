# 本日の業務を開始する

1. `scripts/now.ps1` を実行し、`date=` `time=` `weekday=` を取得する（procedures/powershell.md 参照）。
2. `10_Daily/YYYY/MM/` が無ければ `New-Item -ItemType Directory -Force` で作成する。
3. `DD.md` が既にあれば上書きせず、内容を読んで「開始済み」と伝え、再開する。無ければ .foam/templates/daily-note.md から作成する。
   - `${FOAM_DATE_*}` は今日の値で埋める。weekday は now.ps1 の `weekday=` の値を使う。`foam_template` のブロックは書き込まない。
   - 「前:」には、前回のdaily（今日より前で直近に存在するもの）へのパス付きリンク `[[10_Daily/YYYY/MM/DD|前回]]` を書く。前回のdailyが無ければ `前: なし` とする。「次:」はテンプレートのまま残す。
   - Foam の Alt+D で作られた既存の `DD.md` は、「前:」が `[[02|前回]]` のような識別子だけのリンクになっている。パス付きでなければ、パス付きに直す。
4. 前回のdailyの「📎 その他」にある「次:」の後ろを、今日へのリンク `[[10_Daily/YYYY/MM/DD|次回]]` に置き換える。すでに今日へのリンクなら何もしない。「次:」が無ければ追加しない。
5. 前回のdailyの「次回への持ち越し」を読み、持ち越しが存在すれば「繰り越し（前日の未完了タスク）」に追加する。
6. 「やること」に今日の候補を書き込む（持ち越しを先頭に）。
7. 報告は3〜5行: ファイルパス、計画の件数、持ち越しの件数。「変更があれば言ってください」と添える。使用した MCP サーバー・Agent Skill の1行は、この行数に含めず別に添える（AGENTS.md の「記録ルール」）。

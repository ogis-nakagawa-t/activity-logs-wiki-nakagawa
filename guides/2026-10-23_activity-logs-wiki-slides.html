01 準備

よく使う安全なコマンドは確認なしで通し、削除と push は設定とフックで禁止している

区分対象狙い
確認なしで許可
  • scripts/ の実行、Get-ChildItem、Test-Path、New-Item -ItemType Directory、Move-Item
  • git の status・diff・log・add・commit・remote・fetch template・show・rev-parse と submodule の add・update・status
  • check_evidence.py と knowledge-graph-extend.py の実行、ナレッジグラフの中間ファイルの削除（rm -rf 90_Wiki/.ua/intermediate）
毎日の記録とコミットのたびに承認を求められないようにする
禁止
  • Remove-Item・del などの削除系、git push、git reset --hard
  • Foam MCP の書き込み系ツールと、.env の読み取り
記録の消失と、GitHub 上の履歴の書き換えを防ぐ
フック
  • Bash・PowerShell の前に command-guard.ps1 が削除系と push を拒否し、rm は上の中間ファイルの削除だけを通す
  • Write か Edit のたびに secret-scan.ps1 が機密らしき文字列を探し、マスクを促す
設定では書けない「この形だけ許す」を判定し、認証情報が残るのを防ぐ
プラグインunderstand-anything（ナレッジグラフ）を project スコープで有効にし、版をタグで固定する（版が上がったら、登録済みの PC は登録し直す）全員が同じ版を使う
MCP サーバーは settings.json の enabledMcpjsonServers で有効になり、個人の設定は .claude/settings.local.json（.gitignore 済み）に書く
